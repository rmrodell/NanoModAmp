Drift / risks
-------------
- Preprocessing tools (cutadapt, umi_tools, minimap2, samtools, seqtk) are the exact binaries/versions the runs logged.
- R package versions for counting are current, not verified as the 2025 versions. Rsamtools pileup is
  deterministic, so drift would show up as V1 count differences, not noise.
- umi_tools dedup --method directional: with equal-count UMIs it picks a representative read, and that choice
  depends on input order. Same reads in the same order should give the same choice, but L1 should confirm it.
- The interactive session environment (code-server/R 4.2.0 stack) makes `ml py-cutadapt/1.18_py36` fail with a
  toolchain conflict, and ~/.local/bin/cutadapt is a broken python3.9 install. Source env.sh (module purge) first.
- analysis_endo.R cannot run unmodified: R 4.2.0 lacks lme4/car, and R 4.3.2 lacks ggrepel. Needs Becca's
  decision (an approved install of ggrepel into the 4.3 user library) before V2 endogenous site calling.
